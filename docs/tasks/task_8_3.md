# Task 8.3: Проверка адаптивности на разных экранах

**Этап:** 8 - Тестирование и полировка  
**Приоритет:** Высокий  
**Юзер-кейсы:** Все UC (адаптивность)  
**Зависимости:** Task 8.2

---

## Цель
Убедиться, что приложение корректно работает на всех размерах экрана.

---

## Тест-кейсы

### Desktop (1920x1080 и выше)
- [ ] Layout центрирован с max-width
- [ ] Все элементы видны и доступны
- [ ] Hover эффекты работают
- [ ] Drag-and-drop работает плавно
- [ ] Кнопки действий показываются при hover

### Tablet (768x1024)
- [ ] Layout адаптирован
- [ ] Форма добавления корректна
- [ ] Все кнопки доступны
- [ ] Текст читаем
- [ ] Фильтры умещаются в ряд

### Mobile (375x667 и выше)
- [ ] Форма становится вертикальной (flex-col)
- [ ] Кнопки действий всегда видны
- [ ] Текст не обрезается
- [ ] Touch события работают
- [ ] Фильтры адаптивны
- [ ] Нет горизонтального скролла

---

## Действия

1. Открыть Chrome DevTools (F12)
2. Включить Device Toolbar (Ctrl+Shift+M)
3. Протестировать на разных разрешениях:
   - iPhone SE (375x667)
   - iPad (768x1024)
   - Desktop (1920x1080)
   - 4K (2560x1440)
4. Проверить landscape и portrait ориентации
5. Исправить проблемы с адаптивностью

---

## Критерии приёмки
- ✅ Приложение корректно работает на всех размерах экрана
- ✅ Нет горизонтального скролла на мобильных
- ✅ Все элементы доступны и кликабельны
- ✅ Текст читаем на всех экранах
- ✅ Touch события работают на мобильных
