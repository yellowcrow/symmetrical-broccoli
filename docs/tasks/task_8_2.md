# Task 8.2: Тестирование опциональных фич

**Этап:** 8 - Тестирование и полировка  
**Приоритет:** Высокий  
**Юзер-кейсы:** UC-5, UC-6, UC-7, UC-8 (проверка)  
**Зависимости:** Task 8.1

---

## Цель
Провести тестирование опциональной функциональности.

---

## Тест-кейсы

### UC-5: Редактирование задачи
- [ ] Кнопка Edit открывает режим редактирования
- [ ] Можно изменить текст задачи
- [ ] Enter сохраняет изменения
- [ ] Escape отменяет редактирование
- [ ] Пустой текст не сохраняется
- [ ] Edit disabled для выполненных задач

### UC-6: Фильтрация задач
- [ ] Фильтр "All" показывает все задачи
- [ ] Фильтр "Active" показывает только невыполненные
- [ ] Фильтр "Completed" показывает только выполненные
- [ ] Счётчики на кнопках корректны
- [ ] Активный фильтр визуально выделен
- [ ] Сообщение при пустом результате фильтрации

### UC-7: Перетаскивание задач
- [ ] Задачи можно перетаскивать мышью
- [ ] Визуальная обратная связь при drag
- [ ] Порядок меняется после drop
- [ ] Порядок сохраняется в state

### UC-8: localStorage
- [ ] Задачи сохраняются автоматически
- [ ] После F5 задачи восстанавливаются
- [ ] Сохраняются статусы задач
- [ ] Сохраняется порядок задач
- [ ] Сохраняется активный фильтр

---

## Действия

1. Пройти все тест-кейсы вручную
2. Проверить совместную работу фич (например, drag-and-drop + localStorage)
3. Зафиксировать найденные баги
4. Исправить проблемы
5. Повторить тестирование

---

## Критерии приёмки
- ✅ Все опциональные UC работают корректно
- ✅ Фичи работают совместно без конфликтов
- ✅ Нет регрессий в базовой функциональности
- ✅ localStorage работает стабильно
