# Task 8.1: Тестирование базовой функциональности

**Этап:** 8 - Тестирование и полировка  
**Приоритет:** Высокий  
**Юзер-кейсы:** UC-1, UC-2, UC-3, UC-4 (проверка)  
**Зависимости:** Task 7.3

---

## Цель
Провести комплексное тестирование обязательных функций приложения.

---

## Тест-кейсы

### UC-1: Просмотр списка задач
- [ ] Пустой список показывает placeholder
- [ ] Добавленные задачи отображаются в списке
- [ ] Выполненные задачи визуально отличаются
- [ ] Статистика показывает правильные числа
- [ ] Список адаптивен на разных экранах

### UC-2: Добавление задачи
- [ ] Можно добавить задачу через Enter
- [ ] Можно добавить задачу через кнопку "Add"
- [ ] Пустая задача не добавляется
- [ ] Поле очищается после добавления
- [ ] Новая задача появляется в списке
- [ ] Кнопка disabled для пустого поля

### UC-3: Отметка выполненной
- [ ] Клик по checkbox переключает статус
- [ ] Выполненные задачи зачёркнуты
- [ ] Можно снять отметку выполнения
- [ ] Статистика обновляется

### UC-4: Удаление задачи
- [ ] Кнопка Delete удаляет задачу
- [ ] Задача исчезает из списка
- [ ] При удалении всех задач показывается placeholder
- [ ] Статистика обновляется

---

## Действия

1. Открыть приложение в браузере
2. Пройти все тест-кейсы вручную
3. Зафиксировать найденные баги
4. Исправить критичные проблемы
5. Проверить на разных браузерах (Chrome, Firefox, Safari)

---

## Критерии приёмки
- ✅ Все обязательные UC работают без ошибок
- ✅ Нет критичных багов
- ✅ Нет ошибок в консоли браузера
- ✅ Работа проверена в основных браузерах
