# Task 1.3: Настройка структуры папок проекта

**Этап:** 1 - Инициализация проекта  
**Приоритет:** Критический  
**Юзер-кейсы:** Базовая подготовка для всех UC  
**Зависимости:** Task 1.1

---

## Цель
Создать структурированную архитектуру папок для организации кода.

---

## Изменения по файлам

### Создать структуру папок в `src/`
```
src/
├── components/     # React компоненты
├── store/          # Redux store и slices
├── types/          # TypeScript типы и интерфейсы
├── utils/          # Утилитарные функции
├── App.tsx
├── main.tsx
└── index.css
```

### Команды для создания
```bash
cd src
mkdir components store types utils
```

### Очистить стартовые файлы
- Удалить `src/App.css` (если не удалён в Task 1.2)
- Очистить содержимое `src/App.tsx` до минимального компонента:

```tsx
function App() {
  return (
    <div className="min-h-screen bg-gray-100">
      <h1 className="text-3xl font-bold text-center pt-10">Todo List</h1>
    </div>
  );
}

export default App;
```

---

## Интеграция
После выполнения этой задачи:
- Структура папок готова для размещения компонентов и логики
- Стартовый App.tsx очищен от демо-кода

---

## Тест-кейсы
1. Проверить наличие всех папок в `src/`
2. Запустить `npm run dev`
3. Убедиться, что отображается заголовок "Todo List"
4. Проверить, что нет ошибок компиляции
