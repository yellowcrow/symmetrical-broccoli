# Task 1.1: Инициализация Vite проекта с React + TypeScript

**Этап:** 1 - Инициализация проекта  
**Приоритет:** Критический  
**Юзер-кейсы:** Базовая подготовка для всех UC  
**Зависимости:** Нет

---

## Цель
Создать новый проект с использованием Vite, React и TypeScript.

---

## Изменения по файлам

### Создать новый проект
```bash
npm create vite@latest todo-app -- --template react-ts
cd todo-app
npm install
```

### Установить дополнительные зависимости
```bash
npm install @reduxjs/toolkit react-redux
npm install -D @types/react @types/react-dom
```

---

## Интеграция
После выполнения этой задачи:
- Проект должен запускаться командой `npm run dev`
- Должна открываться стандартная стартовая страница Vite + React

---

## Тест-кейсы
1. Запустить `npm run dev`
2. Открыть http://localhost:5173
3. Убедиться, что приложение загружается без ошибок
4. Проверить, что TypeScript работает (нет ошибок компиляции)
