# План разработки Todo List приложения

**Дата создания:** 2026-01-30  
**Основа:** docs/tz.md  
**Технологический стек:** Vite + React + TypeScript + Redux Toolkit + Tailwind CSS

---

## 1. Подход к реализации

Используется подход **"сверху вниз"**:
1. Инициализация проекта и базовая настройка
2. Создание заглушек компонентов и Redux store
3. E2E интеграция с заглушками
4. Поэтапная реализация функциональности
5. Реализация опциональных фич

Каждая задача связана минимум с одним юзер-кейсом из ТЗ.

## 6. Технические решения

### 6.1 State Management
- **Redux Toolkit** для глобального состояния
- **createSlice** для создания reducer и actions
- **useSelector** и **useDispatch** для доступа к state

### 6.2 Drag and Drop
- Рекомендуется библиотека **@hello-pangea/dnd** (fork react-beautiful-dnd)
- Альтернатива: **dnd-kit** (более современная)

### 6.3 LocalStorage
- Middleware или useEffect для автосохранения
- Загрузка initial state из localStorage при инициализации store

### 6.4 Типизация
```typescript
interface Todo {
  id: string;
  text: string;
  completed: boolean;
  createdAt: number;
  order?: number; // для drag-and-drop
}

type TodoFilter = 'all' | 'active' | 'completed';
```

## 8. Примечания для разработчиков

1. **Начать с обязательных UC:** Сначала реализовать этапы 1-5, затем переходить к опциональным
2. **Использовать компонентный подход:** Каждый компонент должен быть максимально независимым
3. **Следовать принципам Redux Toolkit:** Использовать immer, createSlice, избегать мутаций
4. **Применять Tailwind утилиты:** Избегать кастомного CSS, использовать классы Tailwind
5. **Валидация на уровне UI:** Проверять пустые поля перед отправкой action
